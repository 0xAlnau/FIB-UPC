## Petita Descripció:
Assignatura optativa. Durant el quadrimestre s'ensenya com fer un joc 2D amb OpenGL i un joc 3D amb Unity (els dos jocs estan basats en uns que ja existeixen). També s'explica teoria cada setmana, per després poder fer l'examen final. 

## Opinió Personal:
- Molta càrrega de treball, molta.
- No la recomano fer en un quadrimestre amb PROP o amb IA, o amb assignatures difícils.
- Molt divertida això sí, és curiós veure com funciona un videojoc per dintre i com es programa.
