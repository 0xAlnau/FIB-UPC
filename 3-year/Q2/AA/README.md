## Petita Descripció:
Assignatura optativa de Computació. És la continuació d'Algorismia (A) i es els següents temes nous: Classes de Complexitat; Algorismes Aleatoris; Algorismes d'Aproximació; Programació Lineal/Entera; Kernelització; Teoria de Jocs.

## Opinió Personal:
- Completament diferent a Algorismia. Les classes de teoria són molt complicades i difícils de seguir, però, abans dels exàmens es diu amb antelació una llista de problemes que poden entrar a l'examen (per exemple 7) i després la profe escolleix 3 o 4 d'aquesta llista.
- Cada setmana s'han d'anar fent problemes per a les classes de laboratori. Complicats de collons.
- També hi ha un treball en grup amb 3 o 4 persones, tracta sobre un problema de complexitat, com Clique.
